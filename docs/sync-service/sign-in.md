# Signing In
{: .no_toc }

![Sign In Page](/assets/images/screenshots/light-mode/alr-370-100-sign-in.png)
{: .mx-auto .float-md-right }

The *Sign In* page is used to provide the credentials for the [Aisleron Sync Service](index). The sync service being used is displayed in the *Connecting to* field.

Enter the email and password for a registered account, and click *Sign in* to connect to the sync service.

To register an account for a custom sync service, see [Adding a User Account](self-managing#adding-a-user-account).
